# 台湾語の歌詞で発音練習（試用版）
台湾語の歌詞・文章を利用者が貼り付け、単語ごとの読み・録音・参考の意味を確認する静的アプリです。ビルド不要。GitHub Pagesのmain / (root)で配信できます。
歌詞や楽曲の録音は同梱していません。入力はブラウザ内で処理し、保存や外部API送信をしません。

## 使い方
歌詞を貼り付け「台湾語の発音を調べる」を押す。元の行ごとに単語を縦に表示。主な読みを仮選択し、違う場合だけ選び直す。録音がある候補を単語ごとに再生する。共用録音は「辞書の録音を聞く」と区別する。単語を押すと出典と区切りの編集を開く。

## 仕様と制限
最大5,000文字。長い辞書語を優先する分詞で、文脈や原曲の読みを自動判定しない。表記は本調で、録音には語内変調がある場合がある。未収録の読み・音声を推測したり代用したりしない。
意味は別の台英辞典から中国語対応語と台羅を照合した参考情報。英語原文と出典を確認できる。日本語訳はAI翻訳50項目の小規模試作で、全件人手校閲済みではない。
22,298録音を37個の音声パックに梱包（録音バイト列は元データと同一）。最初の再生では必要な約8MB以下のパックを取得するため待ち時間がある。全音声をページ表示時にダウンロードしない。
スマホ実機での動作確認は未完了。
